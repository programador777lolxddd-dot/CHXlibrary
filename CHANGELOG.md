# Historial de cambios

Los cambios importantes de CHXLibrary se documentan en este archivo.

## [0.1.0] - 2026-10-28

### Añadido
- Utilidades para texto, números, fechas, archivos y funciones creativas.
- README en español con instalación, ejemplos y referencia de funciones.
- Pruebas automatizadas con pytest.
- Workflow de integración continua para probar Python 3.8, 3.10, 3.12 y 3.13.
- Comando de terminal `chrotrixurum` y ejecución mediante `python -m chrotrixurum`.

### Mejorado
- Metadatos de empaquetado y enlaces del proyecto.
- Validación de entradas negativas en algunas funciones.
- Mensajes y documentación de las funciones.
